To avoid maintaining two copies of the same documentation, this page stays minimal. For the full feature list, controls, configuration, and troubleshooting, please see the [url=https://www.nexusmods.com/kingdomcomedeliverance2/mods/3263]KCD2 mod page[/url] - it all applies here as well.

[size=5]Installation[/size]
This is an [b].asi[/b] plugin and requires an [b]ASI loader[/b], which is [b]not bundled[/b] in the download.

[size=4]Find the installation folder[/size]
Open your KC:D installation folder, then open the Bin/Win64 subfolder that contains [b]WHGame.dll[/b] and [b]KingdomCome.exe[/b]. On Steam this is:
[code]<KC:D installation folder>/Bin/Win64/[/code]
Use WHGame.dll to identify the correct folder. The loader and mod files go directly into this folder.

If you have the older [url=https://www.nexusmods.com/kingdomcomedeliverance/mods/2009]KCD1_TPVToggle[/url] mod installed, remove KCD1_TPVToggle.asi and KCD1_TPVToggle.ini first. TPVCamera replaces it, and running both camera mods at once will conflict. To keep a backup, move the old ASI outside the game folder or rename its extension to .asi.bak.

[size=4]Step 1: Install an ASI loader[/size]
If you already have a working ASI loader for KC:D, skip to Step 2. The same loader can load TPVCamera and other ASI mods.

Download [b]one x64[/b] variant of [url=https://github.com/ThirteenAG/Ultimate-ASI-Loader/releases]Ultimate ASI Loader[/url] by ThirteenAG:
[list]
[*][url=https://github.com/ThirteenAG/Ultimate-ASI-Loader/releases/download/x64-latest/dinput8-x64.zip][b]dinput8.dll[/b][/url] - Usual choice if dinput8.dll is unused.[/*]
[*][url=https://github.com/ThirteenAG/Ultimate-ASI-Loader/releases/download/x64-latest/version-x64.zip][b]version.dll[/b][/url] - Alternative when dinput8.dll is already used, including by KCSE.[/*]
[*][url=https://github.com/ThirteenAG/Ultimate-ASI-Loader/releases/download/x64-latest/winmm-x64.zip][b]winmm.dll[/b][/url] - Another alternative if version.dll is also used or does not load.[/*]
[/list]
Extract the DLL from the chosen ZIP directly beside WHGame.dll. Use the [b]x64[/b] build, not Win32, and install only one Ultimate ASI Loader variant. Do not overwrite a DLL belonging to another mod.

[b]Using [url=https://www.nexusmods.com/kingdomcomedeliverance/mods/2244]Kingdom Come Script Extender (KCSE)[/url]?[/b] KCSE uses [b]dinput8.dll[/b]. Keep KCSE's file and install Ultimate ASI Loader as [b]version.dll[/b] or [b]winmm.dll[/b] in the same folder. Choose an unused name from the downloads above; do not rename or replace KCSE's DLL.

[size=4]Step 2: Install the mod[/size]
Download the TPVCamera release archive from the Files tab or [url=https://github.com/tkhquang/KCD1Tools/releases]GitHub Releases[/url]. Extract its contents directly into the [b]same folder[/b] beside WHGame.dll and your loader DLL, without an extra archive-named subfolder.
[list]
[*][b]KCD1_TPVCamera.asi[/b] - The mod.[/*]
[*][b]KCD1_TPVCamera.ini[/b] - Hotkeys and global settings.[/*]
[*][b]KCD1_TPVCamera_presets.json[/b] - Created on first run; not included in the archive.[/*]
[/list]
TPVCamera does not use the Mods folder.

[size=4]Step 3: Launch and verify[/size]
Launch the game; third-person turns on automatically once you reach gameplay. Press F3 (or hold LB + RB on a controller) to toggle back to first-person.

[b]How to verify the mod loaded:[/b] check for [b]KCD1_TPVCamera.log[/b] beside the ASI. If it is missing, check that the ASI and x64 loader DLL are directly beside WHGame.dll, then try another unused loader variant and relaunch. Replace only the Ultimate ASI Loader DLL you installed; keep KCSE and other mods' DLLs. On Wine/Proton, also check the override below.

When updating, back up your customized INI before extracting the new archive, then reapply your settings to the supplied INI. Keep KCD1_TPVCamera_presets.json to retain your saved camera presets.

[b]Folder layout[/b] (everything goes in the binary folder, next to WHGame.dll):
[code]
Bin/Win64/
|-- WHGame.dll                         (game file, already present)
|-- dinput8.dll                        (ASI loader; see KCSE note above)
|-- KCD1_TPVCamera.asi                  (this mod)
|-- KCD1_TPVCamera.ini                  (settings)
|-- KCD1_TPVCamera_presets.json         (created on first run)
\-- KCD1_TPVCamera.log                  (created when the mod loads)
[/code]
With KCSE, dinput8.dll in this example belongs to KCSE; your chosen ASI loader, version.dll or winmm.dll, sits alongside it.

[size=5]Linux / Steam Deck (Wine/Proton)[/size]
Add an override for your chosen loader DLL in the game's [b]Properties -> Launch Options[/b] on Steam:
[code]WINEDLLOVERRIDES="dinput8=n,b" %command%[/code]
Use version=n,b or winmm=n,b instead when using that loader name. If you also use KCSE's dinput8.dll with the version.dll loader, retain both overrides:
[code]WINEDLLOVERRIDES="dinput8,version=n,b" %command%[/code]
For a command-line launch, set the same WINEDLLOVERRIDES value before your launch command. Keep any overrides your other mods need.

[size=5]Configuration[/size]
Hotkeys and settings live in KCD1_TPVCamera.ini (every option is documented inline). Defaults: toggle third-person F3 (or hold LB + RB), free-look orbit F4, preset overlay Home. The camera framing is preset-driven; open the in-game overlay (Home) to tune and save presets. The INI layout and overlay are identical to the KCD2 mod, so its [url=https://www.nexusmods.com/kingdomcomedeliverance2/mods/3263]mod page[/url] documents everything in detail.

[b]After a game update:[/b] the mod locates each game function it hooks through several fallback signatures and self-heals internal data offsets, so it adapts to many game changes automatically. Major updates may still need a mod update if core game functions are heavily rewritten.
