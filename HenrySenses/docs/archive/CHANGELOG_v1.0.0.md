## First Release

- Press a key to highlight nearby loot: bodies, animal carcasses, dropped items and containers
- Herbs and mushrooms get green outlines
- Highlights show through walls and grass, and right up to the camera
- Optional groups for living people, animals, horses, dogs and objects such as doors, beds and workstations
- Highlight any object by its model name, scenery included, such as every barrel or fence
- Vegetables and other plant-like items, such as garlic, get outlines too
- Stolen and empty tags follow the game's own rules, so stolen loot can show in red or stay hidden
- Wild game does not count as stolen once you have the hunting permit perk, while owned livestock does
- Animal carcasses you have not looted yet show as loot, not as empty
- Colors, range, duration, hotkeys and activation mode are set per group, with controller support
- Settings apply as soon as you save the INI
- If a game update breaks one feature, only that feature turns off and the log names it
